# Efficient-2D-LDM-for-Cross-Modality-MRI-Synthesis-with-Clinically-Aligned-Evaluation
2D latent diffusion model for T1ce→FLAIR MRI synthesis (BraTS 2020), benchmarked against GAN/Transformer baselines using clinical detectability metrics (gCNR, gSNR, d′) alongside PSNR/SSIM. Trained on a single consumer GPU.
